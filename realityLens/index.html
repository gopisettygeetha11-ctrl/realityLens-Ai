Streamlit Deployment Guide (Streamlit Community Cloud)

  1. Push this repository to your GitHub account.
  2. Visit share.streamlit.io and sign in with GitHub.
  3. Click New app and select this repository.
  4. For the Places app: set Main file path to ai_places_app/app.py
  5. For the Delivery app: deploy another instance with Main file path set to delivery_apps/app.py
  6. Click Deploy — your apps will be live with instant WebSockets and HTTPS!
